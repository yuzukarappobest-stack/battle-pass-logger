# Battle Pass Logger

Battle Pass の BLE 通知を記録し、シュートパワーと推定実回転数を表示するアプリです。

## Web 版

GitHub Pages 用の静的 Web アプリは `docs/` にあります。

- 公開フォルダ: `docs`
- エントリ: `docs/index.html`
- 必要なサーバー処理: なし

GitHub Pages では、リポジトリの Settings > Pages から Branch を `main`、Folder を `/docs` に設定してください。

## Python 版

PC で使う Python/Tkinter 版は `battle_pass_logger3.py` です。

```powershell
.\Start-BattlePassLogger3.bat
```
